# 作品集改版：从「一页简历」到「一座能点开的岛」

> 2026-11-18 · 参考抖音 @阿囤囤《AI 时代的求职新标配：个人作品集》（2026-10-31）

## 一、为什么改

原站是标准简历页：照片首屏 + 关于 + 项目 + 经历。信息齐，但只有一个「读」的动作——
面试官要自己把散在四处的项目拼成你的能力画像。

参考视频的观点可以压缩成一句：**简历说你会什么，作品集证明你做过什么**。它展示的站点把
内容分成「工作 / 研究 / 黑客松 / 内容」四块，做成一个可点击的世界，作品按「可视化成果 +
GitHub/社交链接」呈现。

我们缺的正是那一层：一个让面试官愿意点、并且点开就能看到「问题 → 做法 → 结果」的入口。

## 二、怎么模仿（对照表）

| 视频里的做法 | 本站落地 | 差异 |
| --- | --- | --- |
| 一座岛，四处基地，点开弹面板 | `雨岛`：工作港 / 项目工坊 / 校园灯塔 / 内容营地，右侧抽屉 | 用 SVG 等距插画替代 3D 引擎，零依赖、首屏 42KB |
| 切换森林 / 沙滩 / 浅海 | 未做 | 换主题对求职信息没有增量，先省掉 |
| 底部四个 tab 导航 | 底部停靠栏，键盘 1–4 同步 | 加了 `?zone=build` 深链，方便放进邮件/简历 |
| 项目卡：成果 + 指标 | 每个作品按「问题 → 做法 → 结果」+ 技术标签 + 可点 Demo | 企业项目无公网 Demo，明确写「可面谈演示」，不伪造链接 |
| 链 GitHub / 社交账号 | 内容营地：GitHub、邮箱、电话、源码、可翻的仓库 | 没有社交账号就不编，只放真实可核验的入口 |
| 学生 / 工作 两种模板 | 只做张雨这一版 | 单一用途，不做模板化 |

## 三、信息架构

```
/            雨岛作品集（新首页）
  ├─ 首屏：岛 + 四个标记 + 一句话定位 + 状态/薪资 + PDF 入口
  ├─ 抽屉：01 工作港 / 02 项目工坊 / 03 校园灯塔 / 04 内容营地
  ├─ 索引：七个作品的文字版（不想点岛也能扫）
  ├─ 经历：三行时间线，点开进抽屉
  └─ 联系：邮件 / 复制邮箱 / GitHub
/profile/    长版简历（原首页，保留）
/resume/     打印版（A4，PDF 由它导出）
/resume.pdf  一页 PDF
```

为什么保留三个页面：HR 初筛要 PDF，技术面要能点开的作品，长版留给想细读的人。
三者共用 `src/config.ts`，不会出现两套说法。

## 四、视觉

第一版是「卡通海岛」：亮色草地 + 沙滩压字，插画由生成脚本手写等距多边形拼出来。
问题很明显——它像一张游戏贴图，和深色 UI 打架，也抢不过标题；评审反馈「不够好看」。

第二轮改成 **地形图（topographic map）**，但版式仍带着明显的「深色 + 细线 + 等宽小标签」套路，
和随处可见的 AI 生成页面没有区别。

第三轮装了社区 skill [`anthropics/skills@frontend-design`](https://skills.sh/anthropics/skills/frontend-design)（1.1M 装机量），
按它的自检清单逐条对照，改掉了这些“模板气”：

| 原来的做法 | 为什么改 | 现在 |
| --- | --- | --- |
| 近黑底 + 单一金色 | skill 点名的默认组合 | 暖米纸 `#FAF4E6` + 墨绿字 `#22322C` + 珊瑚 `#E05A3A`（只给主按钮和站点） |
| 全大写 eyebrow、`A · B · C` 元信息串 | 模板感最强的一类装饰 | 去掉 eyebrow，状态信息写成一句人话 |
| 编号标记 01–04 | 四座基点是并列分类，不是步骤序列 | 只标名字 |
| 等宽字体做小标签 | 到处 mono，像终端 | 只在坐标、年份上保留 |
| 按钮尾部 `→` | 套路 | 去掉 |
| 通栏细线 + 零圆角的“报纸版式” | 另一种默认 | 保留细线，但把重点交给地图和标题 |

方向也换了：从「夜里看海」改成「晴天的海图」——海是清透的蓝绿 `#7FD6D2`，天从薄荷白过渡到米色，岛是沙岸 + 浅草绿，整页暖而不闷。

字体换了 **得意黑（Smiley Sans，OFL）** 做标题——按页面实际用字子集化成 84KB 的 woff2 自托管，
中文标题第一次有了自己的形状；正文与拉丁仍用 Geist Variable。

岛最后是「插画地图」而不是纯线稿：沙滩、草地、20 多棵树、码头栈桥、工坊的烟囱、灯塔、两顶帐篷、篝火、旗子、三个小人、海鸥和小帆船，都是在 `tools/gen-map.mjs` 里用等距投影手写生成的，配等高线、指北针、比例尺当底图。输出 `public/island.svg`，无外部资源。
四座基点的建筑位置与页面上的标签坐标（`src/portfolio.ts` 的 `zones[].x / y`）一一对应，改坐标要两边一起改。

## 六、文案原则

- 只写简历能对上号的事实；数字（GPA、周活 2000+、每批 100 个组织）都来自原文
- 企业项目没有公网入口就写「无公网 Demo，可面谈」，不放占位链接
- 学习项目标注「不是线上系统」，AI 辅助脚手架的部分在仓库说明里本来就有标注
- 不写「精通 / 资深 / 主导亿级」这类无法核验的词

## 七、验证记录（2026-11-18）

- `npm run build`：3 页构建通过
- `tools/qa.mjs`：首页 4 图 0 坏图、0 重复 id、0 空链接、0 控制台报错；/profile/、/resume/ 同样干净
- 截图：1280×800、1440×900、1920×1080、390×844 四档，抽屉的桌面/移动形态均检查
- 键盘：1–4 打开、Esc 关闭、Tab 在抽屉内循环、关闭后焦点回到触发按钮
- 深链：`/?zone=build` 直接打开对应抽屉
- 字体：Geist / JetBrains Mono 的 woff2 从 `@fontsource` 打进 `dist/_astro/`；得意黑子集在 `public/fonts/smiley.woff2`（84KB，200 OK），无外链请求

## 八、没做的事

- 没有 push / 部署：GitHub Pages 上的仍是旧版，需要本人确认后推 `main`
- 没有做「切换岛屿 / 沙洲」这类纯氛围交互
- 没有给作品补过程截图（企业项目素材在受限网络里，未取）
- 手机上站点的文字标签隐藏，只留编号，避免地图上文字打架
- 社区 skill 一度装不上：本机代理客户端卡死，`npx skills find` 全空、skills.sh / GitHub 超时。重启代理后恢复，已装 `anthropics/skills@frontend-design`（全局）并按它的自检清单做了第三轮改版
